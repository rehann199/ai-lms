# Product Overview

AI-LMS is a web-based Learning Management System in which language-model features are built into the course workflow. Instructors can generate quizzes and assignments from their own course material; students can summarise lectures, create flashcards and practice questions, and chat with a lecture.

## Users and roles

| Role | What they can do |
|---|---|
| Admin | Create, view and edit courses across the system |
| Instructor (per course) | Manage course resources, generate quizzes and assignments, summarise lectures |
| Student (per course) | Browse resources, summarise lectures, generate flashcards and practice questions, chat with lecture content |

A user can teach one course and be enrolled in another; the dashboard separates "Courses You Teach" from "Courses You're Enrolled In".

## Course workspace

Each course has tabs for Overview, Announcements, Resources, Assignments and AI Tools (students also get Submissions). Resources are grouped into assignments, quizzes, lectures, summaries and flashcards, with upload, download and delete.

## AI features

- **Quiz and assignment generation** from selected course files plus an instructor prompt, with an automated verification step, optional instructor feedback and regeneration, and PDF or notebook output.
- **Lecture summarisation** with a student-supplied focus, downloadable as PDF.
- **Flashcards** from selected lectures, with PDF and JSON export.
- **Practice questions** with easy, medium or hard difficulty.
- **Talk to your lecture**: a chat grounded in the selected lecture documents, with session history.
